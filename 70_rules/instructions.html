In brief

  1. Go through all the spans (in the panel on the left). Recall what is the highlighted harm span.
  2. Write one or more verification rules from which AI determines whether the translations contain harm in the same span or not. The rule must work on every translation, not only on the provided ones.
  3. Click "Verify", wait until AI verifies the rule on translations.
  4. Check the verification result. If it's wrong, rewrite the rule and verify again, or add second rule.
  5. Potentially, add your contrastive translation(s). You must add at least one contrastive translation that passes your rules if all provided translations contain the harm.
  6. Finish the segment:
    • "finished" if the rules are done, all translation pass/fail correctly.
    • "undecidable" if you cannot decide the segment, e.g. when you think there is no harm in the highlighted span.
    • "remove" if e.g. if this span covers the same error in the same content as another span.

What is the harm?

We consider translation as harmful if it causes a problem beyond the misunderstanding itself: someone would have to correct it or apologise for it, be offended or embarrassed by it, laugh at it, or be at risk if they acted on it.

Verification rules

  • Your rule should be framed as generally as possible in testing the highlighted harm rather than hyper-specifically targeting particular wrong translations.
  • Focus: In this task, write verification rules to target only the harm in the highlighted span.
  • Format: Write a short instruction for an AI judge, e.g. “Check whether the translation conveys that the speaker feels no inner peace.”. The rule should clearly have a pass/fail conclusion. The verification rule should be written in English regardless of the source and target languages.
  • Atomicity: Each rule should only be checking for one conceptual issue. If you find yourself listing various separable conditions into a single rule, use multiple rules instead.
  • Granularity: Your verification rule should be specific enough to catch harmful translations but flexible enough to pass any unharmful phrasing.
  • Correctness: Overall result is pass if all rules pass, and fail if any rule fails.

Example rules

  • The company name is "Aptar".
  • The person last name is "Hajde".
  • The person "Andrea" is male gender.
  • The person name is "Vik", it may be spelled as "Vic". Inflected form such as "pro Vika" is fine.
  • There is nothing about that the rate is "interest" ("úroková").

Editor details:

  • Span list (left panel): the mark in front of each span is work status: - pending, ! in progress, . finished, x remove, ? undecidable. Type a mark or a word into the filter to find spans. Spans of the same segment are grouped (├─ / └─), and the header then shows span k / n.
  • Table: there is a translation with highlighted confirmed harm. Other confirmed spans of the same segment are underlined with dashes.
  • Rules: one rule per line (R1, R2, …). Rules suggested in advance may already be there: check, rewrite or delete them.
  • Autosave: Everything is saved automatically.
  • Verdicts: ✓ pass, ✗ fail, ? the AI did not answer; hover over a tick to see the rule and the verdict. overall is ✓ only if a translation passes all rules; it turns red if it differs from human expert.
  • human expert (left of the rules): your own judgement of each translation. The highlighted one is always ✗ (the confirmed harm). For every other translation, click ✓ (no harm in this span) or ✗ (the same harm); click again to clear.
  • Contrastive translations (+ add contrastive translation): your own translations, verified like the others. You can change the description label, such as "correct", "disfluent but not harm", etc.
  • finished is accepted only when there is at least one rule, every translation has your judgement and current verdicts, the overall verdict of the AI judge agrees with human expert for every translation, and at least one translation (a system or a contrastive one) is marked ✓ by you. Click a ticked button again to untick it.
  • Keyboard shortcuts: Ctrl+Enter to verify, Alt+↓ / Alt+↑ for next / previous span.
